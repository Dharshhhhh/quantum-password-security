# Quantum Password Security Simulator

An educational project exploring Grover's quantum search algorithm and its impact on cybersecurity.

## Features
- Interactive dashboard
- Classical vs quantum search comparison
- Quantum circuit simulation using Qiskit
- Measurement result visualization

## Technologies
- Python
- Streamlit
- Qiskit
- Qiskit Aer
- Matplotlib

## Run the Project

Install dependencies:

pip install -r requirements.txt

Start the application:

streamlit run app.py

## Limitations

This is an educational simulation. It does not crack real passwords or attack real encryption systems.
